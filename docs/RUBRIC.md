# 완료 기준

| 항목 | 배점 | 확인 방법 |
|---|---:|---|
| 주문과 체결 | 35 | 사용자 확인 후 주문 1회 제출. 접수·부분체결·취소·결과 불명을 구분하고, 결과 불명은 조회·대사로 해결한다. 중복 체결을 한 번만 반영한다. |
| 데이터와 근거 | 30 | 원장과 그래프를 거래·종목·시점으로 연결한다. 답변의 근거 ID가 조회 결과에 있고, 기준일 이후 근거를 제외한다. |
| Codex 실행 | 20 | 로컬 ChatGPT 인증, 제한된 입력, 구조화된 최종 응답, 실행 실패 판정을 각각 재현한다. |
| 재현과 문서 | 15 | 합성 자료로 흐름을 재현하고, 실제 연결 상태와 다음 작업을 기록한다. |

단계별 인수 조건은 `phases/index.json`에 둔다. 완성된 앱의 인수 기준은 85점 이상 및 P0 0건이다. P0은 주문 중복·미확인 주문의 자동 재전송, 주문 권한이 Codex에 노출되는 경로, 비밀 유출, 체결·잔고 훼손, 허위 완료다. 평가는 합성 검사 결과와 GitHub PR 리뷰의 재현 근거를 따른다. 미구현 기능은 미평가로 남기며 합성 검증을 실계좌 검증으로 간주하지 않는다.
